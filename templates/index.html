Host this API on Vercel

1. Import the GitHub repo

Vercel Dashboard → Add New → Project → import lead-chai-api. Framework preset should detect FastAPI from main.py.

2. Set the API key

Project Settings → Environment Variables:

LEAD_CHAI_API_KEY=lc_live_your_secret_key_here

Or deploy from the CLI:

npm i -g vercel
vercel login
vercel --prod

After deploy, your API URL looks like https://lead-chai-api.vercel.app. Paste that URL into the extension settings.

Load the Chrome extension

  1. Download this repo (or lead-chai-extension.zip) and unzip it.
  2. Chrome-e jaw: chrome://extensions
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the extension folder.
  5. Google Maps khule search dao. Right side-e Lead Chai panel asbe.
  6. Settings-e Vercel API URL + API key boshao, then Scan leads.
